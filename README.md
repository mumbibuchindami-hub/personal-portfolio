Question 2: HTML Elements

1. Which 5 elements did you find most challenging to implement and why?

The five elements I found most challenging were:

* <form> – It required understanding how forms collect information from users and how attributes such as action, method, and type work.
* <table> – Organizing information into rows and columns required careful use of <tr>, <th>, and <td>.
* <nav> – I had to understand how to create navigation links that allow users to move between different sections of the website.
* <article> – It was challenging to decide which pieces of content should be treated as independent articles.
* <iframe> – Understanding how to embed external content inside a webpage required additional attention to its attributes and structure.

2. How did you use semantic elements to structure your content?

I used semantic HTML elements to make the structure of my website clear and meaningful.

* <header> contains the website heading and introductory information.
* <nav> contains the navigation links.
* <main> contains the main content of the webpage.
* <section> separates major areas such as About, Skills, Education, and Projects.
* <article> contains independent pieces of information, such as individual projects.
* <aside> contains additional or related information.
* <footer> contains closing information such as copyright and contact details.

This makes the webpage easier for developers, browsers, and assistive technologies to understand. The assignment specifically requires semantic HTML structure. Assignment 1(IWD).pdf

3. Which element was most useful for organizing your layout and why?

The <section> element was the most useful because it allowed me to divide the website into clear and organized parts. Each section could focus on one topic, such as my education, skills, projects, or contact information.

Question 3: HTML Attributes

1. Which 3 attributes were essential for making your website functional?

The three most important attributes were:

* href – Used with links to allow users to navigate to different sections or pages.
* src – Used to specify the location of images and other embedded resources.
* id – Used to uniquely identify sections and allow navigation links to point directly to those sections.

These attributes helped make the website interactive and functional. The assignment requires analysis of the attributes used in the website. Assignment 1(IWD).pdf

2. How did you use the class and id attributes differently?

I used the id attribute to give a unique name to a specific HTML element. The class attribute was used to group multiple elements that shared a similar purpose or style.Therefore, an id is normally unique, while a class can be used on multiple elements.

3. Which attribute helped improve user experience the most and why?

The alt attribute helped improve the user experience the most. It provides alternative text for images. If an image cannot load, the text can explain what the image represents. It also improves accessibility for users who rely on screen readers.

Question 4: Development Process

1. How did you plan your website structure before coding?

Before coding, I first decided that I would create a personal portfolio website. I then listed the information I wanted to include, such as my introduction, education, skills, projects, hobbies, and contact information.

After that, I planned the HTML structure using semantic elementsThis helped me organize the content before writing the actual code.

2. What was your approach to testing and debugging your HTML?

I tested the website by opening the HTML file in a web browser. I checked whether all sections, links, images, forms, and other elements worked correctly.

When I found an error, I inspected the HTML code and corrected issues such as missing closing tags, incorrect attributes, and incorrectly nested elements. I then refreshed the browser and tested the website again.

3. What challenges did you face and how did you overcome them?

One challenge was remembering the correct syntax and attributes for different HTML elements. I overcame this by referring to my HTML notes and checking the structure of my code carefully.

Another challenge was organizing many different elements while keeping the code readable. I overcame this by using indentation, comments, headings, and semantic sections.

I ensured my HTML was valid by checking that tags were properly opened and closed, elements were correctly nested, and attributes were written using the correct syntax.
